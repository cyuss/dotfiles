# AeroSpace Cheat Sheet

## Hyper Key
`Hyper = cmd + alt + ctrl + shift`

## Main Mode
- `Hyper + h/j/k/l`: Focus left/down/up/right
- `Hyper + ←/↓/↑/→`: Focus left/down/up/right
- `Hyper + a/s/w/d`: Move window left/down/up/right
- `Hyper + space`: Toggle layout `tiles <-> accordion`
- `Hyper + enter`: Toggle layout `floating <-> tiling`
- `Hyper + f`: Fullscreen (AeroSpace)
- `Hyper + g`: Native macOS fullscreen
- `Hyper + r`: Enter resize mode
- `Hyper + 1..9`: Switch to workspace `1..9`
- `Hyper + 0`: Switch to workspace `1`
- `Hyper + n`: Enter workspace-send mode
- `Hyper + b`: Workspace back-and-forth
- `Hyper + m`: Move current workspace to next monitor
- `Hyper + ;`: Enter service mode
- `cmd + tab`: App suivante (compatible fullscreen)
- `cmd + shift + tab`: App précédente (compatible fullscreen)
- `cmd + alt + tab`: App suivante (fallback)
- `cmd + alt + shift + tab`: App précédente (fallback)

## Resize Mode
- `h`: Resize smart `-50`
- `l`: Resize smart `+50`
- `j`: Resize height `+50`
- `k`: Resize height `-50`
- `1`: Preset `1/3` (exact on a 2-window split)
- `2`: Preset `2/3` (exact on a 2-window split)
- `b`: Balance sizes
- `esc` or `enter`: Return to main mode

## Workspace-Send Mode
- `1..9`: Move focused window to workspace `1..9`, switch there, return main mode
- `0`: Move focused window to workspace `1`, switch there, return main mode
- `esc` or `enter`: Return to main mode

## Service Mode
- `esc`: Reload config and return main mode
- `r`: Flatten workspace tree and return main mode
- `f`: Toggle floating/tiling and return main mode
- `backspace`: Close all windows except current and return main mode
- `q`: Close focused window and return main mode
