08Le débogueur (dape)

dape parle DAP directement, sans dépendre de lsp-mode. Le module Doom :tools debugger reste désactivé parce qu'il tire dap-mode et realgud pour rendre le même service.

prérequis, une seule fois par projetuv add --dev debugpy. L'adaptateur lance python -m debugpy.adapter ; comme my/python-apply-local-venv a déjà posé exec-path et PATH localement au tampon, python désigne le bon interpréteur sans rien déclarer. Si le paquet manque, dape le dit franchement : module debugpy is not installed.

La séquence

  1. Poser un point d'arrêt sur la ligne voulue : SPC d b
  2. Démarrer : SPC d d — dape demande la configuration (debugpy), puis le fichier ou le module
  3. L'exécution s'arrête. Les panneaux (pile, variables, points d'arrêt) s'ouvrent à droite ; le code reste à gauche
  4. Avancer : SPC d n pas à pas, SPC d i entrer dans l'appel, SPC d o en sortir
  5. Inspecter une expression : SPC d E — ou lire les valeurs affichées en ligne dans le code (dape-inlay-hints)
  6. Terminer : SPC d q. Les points d'arrêt sont sauvegardés et rechargés au démarrage suivant

Mesurer une lenteur pendant qu'elle se produit

le seul protocole fiableAucune mesure sans interface n'est crédible pour du rendu interactif : la lenteur doit être capturée pendant qu'elle a lieu, dans une vraie fenêtre.
  1. SPC P s — démarre le profileur (cpu + mémoire)
  2. Reproduire la lenteur pendant 10 à 20 secondes
  3. SPC P r — ouvre le rapport et arrête le profileur. TAB déplie les branches ; la fonction coupable est en haut de la branche la plus lourde
  4. SPC P x — remettre les compteurs à zéro avant une nouvelle mesure

Défilement animé

Sans paquet supplémentaire. Emacs 29+ fournit pixel-scroll-precision-mode et son moteur d'interpolation — le même que celui du trackpad. evil-scroll-down et evil-scroll-up y sont simplement redirigés.

pourquoi c'est sans risqueL'interpolation ne tourne que pendant l'exécution d'une commande de défilement. Elle n'ajoute rien au rendu, rien à un déplacement de curseur, rien à la frappe. Le seul coût est la durée de l'animation elle-même : +smooth-scroll-time = 0,10 s. Mettre cette variable à 0 désactive tout.
